# PE_TTM（滚动市盈率）因子

## 因子概述

PE_TTM (Price-to-Earnings Trailing Twelve Months) 是衡量股票估值水平的核心指标，等于总市值除以最近四个季度归属于母公司股东的净利润之和。

\[
PE\_TTM = \frac{\text{总市值}}{\text{归母净利润(TTM)}}
\]

## 数据来源

| 数据项 | 主板表 | 科创板表 | 频率 |
|--------|--------|----------|------|
| 归母净利润(TTM) | `LC_FSDerivedData` (公司衍生报表数据_新会计准则(新)) | `LC_STIBDerivedData` (科创板衍生报表数据) | 季频 |
| 总市值 | `QT_Performance` (股票行情表现) | `LC_STIBPerformance` (科创板行情表现) | 日频 |

### 单位换算

- **主板总市值**：原始单位为**万元**，代码中 ×10000 转换为元
- **科创板总市值**：原始单位为**元**，先 ÷10000 统一为万元，再参与统一计算

### 数据合并策略

采用 `fo.Where(主板因子, fo.NotNull(主板因子), 科创板因子)` 模式：
- 主板有数据时优先使用主板数据
- 主板缺失时以科创板数据填充

## 注意事项

1. **负 PE_TTM**：当公司归母净利润为负时，PE_TTM 为负值，这在回测中通常需要过滤
2. **极大值**：当净利润接近 0 时，PE_TTM 会趋近无穷大，建议在截面分析中进行截尾处理（如 1%~99% winsorize）
3. **金融行业**：银行、保险等金融类公司的净利润口径与一般企业不同，PE_TTM 的横向可比性有限
4. **数据时效**：TTM 数据随财报公告更新（季频），在两次财报之间保持不变；总市值逐日更新
