## 设计目标

1. **全功能平台**：覆盖因子管理、回测、风险建模、组合优化、报告生成等核心功能
2. **小团队协作**：支持多用户使用，基本的权限管理和数据隔离
3. **长期维护**：前后端分离架构，清晰的 API 边界，便于扩展和维护

## 核心特性

- 动态表单生成：基于 QSArgs 的 traits 自动生成 Web 表单
- DAG 可视化：因子依赖关系的交互式图形展示
- 异步任务处理：长时间计算任务的进度推送
- 数据预览优化：分页加载和虚拟滚动支持大表格

## 与现有系统的关系

| 现有组件 | Web GUI 关系 |
|----------|-------------|
| `QSExt/GUI/Notebook/` | 保留，用于快速原型和 Jupyter 用户 |
| `QSExt/GUI/QtGUI/` | 保留，用于桌面用户 |
| `QSExt/QSRegistry/` | Web GUI 后端直接调用 QSGraphDB API |
| `QSExt/ReportGenerator/` | Web GUI 复用组件库和渲染器 |
| `QuantStudio/Factor/` | Web GUI 通过 Service 层桥接 |
