# 功能模块

基于现有 GUI 和核心模块分析，Web GUI 分为 6 个主要功能模块。

## 1. 数据管理 (Data Manager)

### 功能清单

```
├── 因子库连接管理
│   ├── 添加/编辑/删除连接配置
│   ├── 连接状态监控
│   └── 支持的后端：HDF5/ClickHouse/MongoDB/Neo4j/SQLite/...
├── 因子浏览 (树形结构)
│   ├── FactorDB → FactorTable → Factor 层级
│   ├── 延迟加载（展开时查询）
│   ├── 右键菜单（重命名/删除表、重命名/删除/批量删除因子）
│   └── 点击表节点查看表信息、点击因子节点查看因子数据
├── 数据预览
│   ├── DataGrid 表格展示
│   ├── 日期/ID 范围选择
│   └── 缺失值过滤
├── 元数据编辑
│   ├── 因子元数据行内编辑
│   ├── 因子表元数据行内编辑
│   └── 保存
```

### 界面设计

```
┌─────────────────────────────────────────────────────────────┐
│  数据管理                                    [+ 添加连接]   │
├──────────────┬──────────────────────────────────────────────┤
│              │  连接配置                                     │
│  因子库      │  ┌────────────────────────────────────────┐  │
│  ├─ HDF5DB   │  │ 名称: HDF5DB                          │  │
│  ├─ ClickH.. │  │ 类型: HDF5                            │  │
│  ├─ MongoDB  │  │ 路径: /data/factors                   │  │

│              │  └────────────────────────────────────────┘  │
│  因子表      │                                              │
│  ├─ Stock    │  因子列表                                    │
│  │  ├─ PE    │  ┌────────────────────────────────────────┐  │
│  │  ├─ PB    │  │ 因子名  │ 类型   │ 截止日  │ 证券数  │  │
```

### API 设计

```python
# 因子库连接管理
GET    /api/connections/                 # 获取连接列表
POST   /api/connections/                 # 创建连接
GET    /api/connections/{id}             # 获取单个连接
PUT    /api/connections/{id}             # 更新连接
DELETE /api/connections/{id}             # 删除连接
POST   /api/connections/{id}/test        # 测试连接

# 因子浏览
POST   /api/factors/{conn_id}/reconnect  # 重连因子库
GET    /api/factors/{conn_id}/tables     # 获取因子表列表
GET    /api/factors/{conn_id}/tables/{table_name}/factors  # 获取因子列表

# 表管理
PUT    /api/factors/{conn_id}/tables/{table_name}/rename   # 重命名表
DELETE /api/factors/{conn_id}/tables                        # 批量删除表
PUT    /api/factors/{conn_id}/tables/{table_name}/metadata  # 更新表元数据

# 因子管理
PUT    /api/factors/{conn_id}/tables/{table_name}/factors/{factor_name}/rename    # 重命名因子
DELETE /api/factors/{conn_id}/tables/{table_name}/factors                         # 批量删除因子
PUT    /api/factors/{conn_id}/tables/{table_name}/factors/{factor_name}/metadata  # 更新因子元数据

# 数据预览
GET    /api/factors/{conn_id}/tables/{table_name}/factors/{factor_name}/data
    ?start_date=2024-01-01
    &end_date=2024-12-31
    &ids=code1,code2
    &limit=100

POST   /api/factors/{conn_id}/tables/{table_name}/data       # 获取多个因子数据

# 元数据
GET    /api/factors/{conn_id}/tables/{table_name}/factors/{factor_name}/stats     # 因子统计
GET    /api/factors/{conn_id}/tables/{table_name}/factors/{factor_name}/metadata  # 因子元数据
GET    /api/factors/{conn_id}/tables/{table_name}/metadata                        # 表元数据
```

## 2. 因子工作台 (Factor Workbench)

### 功能清单

```
├── 因子搜索
│   ├── 关键词搜索 (QSRegistry)
│   ├── 语义搜索 (Ollama 嵌入)
│   └── 按标签/类型筛选
├── DAG 可视化
│   ├── 依赖关系图 (React Flow)
│   ├── 节点类型着色（因子/因子表/因子库）
│   ├── 点击高亮依赖链
│   └── 缩放/平移/自动布局
├── 衍生因子创建
│   ├── 选择算子 + 依赖因子
│   ├── 参数配置（自动表单生成）
│   └── 预览计算结果
└── 因子元信息管理
    ├── 查看/编辑描述
    ├── 标签管理
    └── 依赖关系分析
```

### 界面设计

```

└────────────────────────────┴────────────────────────────────┘
```

### DAG 节点类型

| 节点类型 | 颜色 | 图标 | 说明 |
|---------|------|------|------|
| 因子库 (FactorDB) | 黄色 | 🗄️ | 数据库连接 |
| 可写因子库 | 橙色 | 📝 | 可写入的数据库 |
| 因子表 (FactorTable) | 浅绿 | 📊 | 因子集合 |
| 自定义因子表 | 深绿 | 📋 | 用户定义的因子表 |
| 原子因子 (AtomicFactor) | 天蓝 | 📈 | 直接从数据源读取 |
| 衍生因子 (DerivativeFactor) | 钢蓝 | 🔗 | 由算子计算得出 |

### API 设计

```python
# 因子搜索
GET /api/factors/search
    ?query=动量
    &limit=20
    &type=atomic|derivative
    &tags=momentum,value

GET /api/factors/search/semantic
    ?query=市盈率变化率
    &limit=20

# 因子详情
GET /api/factors/{qsid}
GET /api/factors/{qsid}/descriptors  # 获取依赖因子
GET /api/factors/{qsid}/dependents   # 获取被依赖因子
GET /api/factors/{qsid}/dag          # 获取完整 DAG 数据

# 因子元信息
PUT /api/factors/{qsid}/metadata
    {"description": "...", "tags": ["tag1", "tag2"]}

# 衍生因子创建
POST /api/factors/derivative
    {
        "name": "PE_ROC",
        "operator": "TimeOperation",
        "descriptors": ["qsid1", "qsid2"],
        "params": {...}
    }
```

## 5. 组合优化 (Portfolio Optimizer)

## 8. 因子挖掘 (Mining Studio)

### 功能清单

```
├── 挖掘任务管理
│   ├── 新建/删除任务
│   ├── 任务列表（框架、状态、运行次数）
│   └── 接续挖掘（从 checkpoint 恢复种群继续进化）
├── 配置面板
│   ├── 框架选择（当前: 遗传规划 GP）
│   ├── 算子多选
│   ├── 终端因子级联选择（FactorDB → 表 → 因子）
│   ├── 种子因子选择（从全局因子池选入，叶节点自动作为终端因子）
│   ├── 从因子定义脚本导入终端因子
│   ├── GP 参数配置（种群大小、代数、变异概率等）
│   └── 适应度评估配置（回测模块 + transform）
├── 结果浏览
│   ├── 适应度进化曲线（Plotly）
│   ├── Hall of Fame 排名表
│   ├── 因子树可视化（React Flow）
│   └── Run 历史切换
└── 持久化
    ├── workspace 目录存储
    ├── Checkpoint 保存（供接续使用）
    └── 因子定义脚本导出（FactorScriptWriter 生成）
```

### 关键架构决策

- **适应度评估复用回测框架**：通过 `_BT_NODE_BUILDERS` 声明式调用 CalcOp + BTNode
- **算子序列化统一**：`FactorOperator.serialize()/deserialize()` 标准接口
- **因子脚本生成**：`FactorScriptWriter.generate_script()` 重建式代码生成
- **全局上下文**：`FactorDefContext` 基于 settings.py 提供可复用的 `FactorDefInput`
