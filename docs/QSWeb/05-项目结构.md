# 项目结构

## 整体目录结构

```
QSWeb/
├── frontend/                    # 前端项目 (React + Vite + Ant Design)
│   ├── src/
│   │   ├── pages/              # 页面组件
│   │   ├── components/         # 通用组件
│   │   ├── services/           # API 调用封装
│   │   ├── stores/             # 状态管理 (Zustand)
│   │   ├── hooks/              # 自定义 Hooks
│   │   ├── types/              # TypeScript 类型定义
│   │   ├── App.tsx
│   │   └── main.tsx
│   ├── public/
│   ├── package.json
│   ├── tsconfig.json
│   └── vite.config.ts
│
├── backend/                     # 后端项目 (FastAPI)
│   ├── app/
│   │   ├── api/                # API 路由
│   │   ├── services/           # 业务服务
│   │   ├── models/             # Pydantic 数据模型
│   │   ├── tasks/              # 异步任务管理器
│   │   ├── core/               # 核心配置
│   │   └── main.py
│   └── requirements.txt
│
├── scripts/                     # 工具脚本
│   ├── migrate_connections.py
│   └── start.ps1
│
├── README.md
├── CLAUDE.md
└── .mcp.json
```

## QSExt 新增/修改文件

本次变更还涉及 QSExt 核心库的修改：

| 文件 | 说明 |
|------|------|
| `QSExt/FactorDef/FactorScriptWriter.py` | 新增：因子对象 → FactorDef 脚本生成器 |
| `QSExt/Tools/OperatorSerializer.py` | 已删除：序列化逻辑已合并到 FactorOperator |
| `QSExt/QSRegistry/QSGraphDB.py` | 修改：`_serializeOperatorNode` 使用 `op.serialize()` |
| `QSExt/QSRegistry/_serialization.py` | 修改：移除废弃的 `serializeOperatorArgs` 等函数 |
| `QuantStudio/Core/__init__.py` | 修改：`model_dump` 输出完整类路径，`serialize/deserialize` 增强 |
| `QuantStudio/Factor/FactorOperation.py` | 修改：`FactorOperator` 重写 `serialize/deserialize` |
