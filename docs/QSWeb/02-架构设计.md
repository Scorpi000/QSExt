## 分层设计

### 1. 表现层（Frontend）

**职责**：
- 用户界面渲染
- 用户交互处理
- 状态管理
- 数据可视化

**主要组件**：
- 页面组件（Pages）：对应 6 个功能模块
- 通用组件（Components）：FactorTree、DataGrid、DAGViewer 等
- 服务层（Services）：API 调用封装
- 状态管理（Stores）：Zustand stores

### 3. 服务层（Service Layer）

**职责**：
- 封装 QuantStudio API 调用
- 业务逻辑处理
- 数据转换和缓存
- 异步任务管理

```python
from QuantStudio.Factor import FactorDB, FactorTable

class FactorService:
    """因子服务 - 桥接 QuantStudio 和 Web API"""

    def __init__(self):
        self._connections: dict[str, FactorDB] = {}

    async def connect(self, db_name: str, config: dict) -> bool:
        """连接因子库"""
        fdb = FactorDB(**config)
        await fdb.connect()
        self._connections[db_name] = fdb
        return True

    async def get_tables(self, db_name: str) -> list[str]:
        """获取因子表列表"""
        fdb = self._connections[db_name]
        return fdb.TableNames

    async def read_data(
        self,
        db_name: str,
        table_name: str,
        factor_names: list[str],
        start_date: date,
        end_date: date,
        page: int = 1,
        page_size: int = 100
    ) -> dict:
        """读取因子数据（分页）"""
        fdb = self._connections[db_name]
        ft = fdb.getTable(table_name)
        # 获取日期和ID范围
        dts = ft.getDateTime(factor_names[0], None, start_date, end_date)
        ids = ft.getID(factor_names[0], dts[-1] if dts else None)
        # 分页处理
        start_idx = (page - 1) * page_size
        end_idx = start_idx + page_size
        # 读取数据
        data = ft.readData(factor_names, ids[start_idx:end_idx], dts)
        return {
            "data": data.to_dict(),
            "total": len(ids),
            "page": page,
            "page_size": page_size
        }
```

### 4. 数据层（Data Layer）

**职责**：
- 数据持久化
- 数据访问封装
- 缓存管理

**数据源**：
- Neo4j：计算图元数据（QSRegistry）
- ClickHouse/HDF5/MongoDB：因子数据
- PostgreSQL：用户、权限、配置
- Redis：缓存、会话、任务队列

## 数据流

### 因子数据读取流程

```
用户请求
    ↓
Frontend: GET /api/factors/{qsid}/data?start_date=...&end_date=...
    ↓
API Layer: 参数验证、路由分发
    ↓
Service Layer: FactorService.read_data()
    ↓
QuantStudio: FactorTable.readData(factor_names, ids, dts)
    ↓
数据源: ClickHouse/HDF5/MongoDB/...
    ↓
Service Layer: 数据转换、分页处理
    ↓
API Layer: 格式化响应
    ↓
Frontend: 渲染 DataGrid 表格
```

### 回测执行流程

```
用户配置回测参数
    ↓
Frontend: POST /api/backtest/run {config}
    ↓
API Layer: 创建异步任务
    ↓
Service Layer: BacktestService.start_task()
    ↓
    ├── 返回 task_id 给前端
    └── 后台执行:
        ├── QuantStudio: Engine.run(backtest_nodes)
        ├── WebSocket: 推送进度更新
        └── 完成后存储结果
    ↓
Frontend: WebSocket 接收进度
    ↓
完成: GET /api/backtest/{task_id}/result
```

## 并发和性能

### 异步处理

```python
import asyncio
from fastapi import BackgroundTasks

@app.post("/api/backtest/run")
async def run_backtest(
    config: BacktestConfig,
    background_tasks: BackgroundTasks
):
    task_id = str(uuid4())
    # 添加后台任务
    background_tasks.add_task(
        execute_backtest,
        task_id,
        config
    )
    return {"task_id": task_id}

async def execute_backtest(task_id: str, config: BacktestConfig):
    """后台执行回测"""
    try:
        # 更新任务状态
        await redis.set(f"task:{task_id}:status", "running")
        # 执行回测
        result = await run_qs_backtest(config)
        # 存储结果
        await redis.set(f"task:{task_id}:result", json.dumps(result))
        await redis.set(f"task:{task_id}:status", "completed")
    except Exception as e:
        await redis.set(f"task:{task_id}:status", "failed")
        await redis.set(f"task:{task_id}:error", str(e))
```

```python
from fastapi import Depends, HTTPException
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security)
):
    """验证 JWT token"""
    token = credentials.credentials
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        return payload
    except jwt.InvalidTokenError:
        raise HTTPException(status_code=401, detail="Invalid token")
```

```python
from enum import Enum

class Permission(str, Enum):
    READ = "read"
    WRITE = "write"
    ADMIN = "admin"

def require_permission(permission: Permission):
    """权限装饰器"""
    async def checker(user = Depends(get_current_user)):
        if permission not in user["permissions"]:
```
