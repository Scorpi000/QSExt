# 信号质量诊断

## 一、概述

信号的预测能力是策略收益的根本来源。信号质量诊断是策略失效分析的**第一入口**——如果信号不再能预测未来收益，策略失效只是时间问题。

**核心发现**（Factor Decay Lab, 2024）：Rolling IC 下降领先净值回撤 3-6 个月，是最有效的领先预警指标。

## 二、IC 分析

### 2.1 截面 Rank IC

**定义**：每个时点上，因子值与未来收益的 Spearman 秩相关系数。

```
RankIC_t = SpearmanCorr(FactorValue_t, ForwardReturn_t→t+h)
```

**输出指标**：

| 指标 | 计算方式 | 预警阈值 |
|------|---------|---------|
| Rank IC 均值 | 滚动窗口内 IC 的算术平均 | 连续 3 个月 < 0.02 |
| ICIR | IC 均值 / IC 标准差 | 滚动 12 个月 < 0.5 |
| IC 胜率 | IC > 0 的期数占比 | 低于 55% |
| IC t 统计量 | 均值 / (标准差/√n) | < 1.5 |

### 2.2 IC 衰减曲线

**定义**：计算因子对 T+1、T+5、T+10、T+20 等不同前瞻期的 IC，观察预测能力的衰减速度。

**实现要点**：

```python
# 伪代码
horizons = [1, 5, 10, 21, 42, 63]  # 前瞻天数
for h in horizons:
    forward_ret = shift(close, -h) / close - 1
    ic = df.corrwith(forward_ret, method='spearman', axis=0)
    ic_mean[h] = ic.mean()
```

**诊断要点**：
- IC 曲线快速下降 → 信号半衰期短，换仓频率需要提高
- IC 曲线在某个前瞻期转负 → 信号有最优持有期，偏离则失效
- IC 曲线整体下移 → 信号预测能力系统性衰减

### 2.3 分层 IC

按维度分组计算 IC，发现失效的细分领域：

| 分层维度 | 分析内容 |
|---------|---------|
| 行业 | 哪些行业的信号 IC 已转负？ |
| 市值分档 | 大/中/小盘上的 IC 分化？ |
| 估值分档 | 高/低估值股票上的 IC 差异？ |

### 2.4 条件 IC

在不同市场环境下分拆 IC：

| 条件 | 分析内容 |
|------|---------|
| 上涨市场 vs 下跌市场 | 信号是否只在单边市有效？ |
| 高波 vs 低波 | 信号在高波动期是否失效？ |
| 风格主导期 | 信号在价值/成长主导期的表现差异？ |

## 三、信号分布漂移检测

### 3.1 为什么重要

策略失效往往表现为**信号值的分布发生了系统性变化**，而非预测关系本身改变。分布漂移检测是区分"暂时失效"和"永久失效"的关键工具。

### 3.2 四大漂移类型

| 漂移类型 | 定义 | 量化策略对应 |
|---------|------|------------|
| **协变量偏移** (Covariate Shift) | P(X) 变化，P(Y|X) 不变 | 因子值的分布变了，但因子与收益的关系没变 |
| **概念漂移** (Concept Drift) | P(Y|X) 变化 | 因子与收益的关系变了（真正的因子失效） |
| **标签偏移** (Label Shift) | P(Y) 变化 | 收益率的分布变了（如市场整体转向） |
| **时序/域偏移** (Temporal Shift) | 整体数据生成过程变化 | 市场微观结构变革 |

### 3.3 检测方法

#### 方法一：KS 检验（Kolmogorov-Smirnov）

**用途**：检测近期信号分布与历史基线分布是否有显著差异。

**原理**：比较两个经验累积分布函数（ECDF）的最大距离。

```
D_{n,m} = sup_x |F_recent(x) - F_baseline(x)|
若 p-value < 0.05 → 分布发生显著漂移
```

**实现建议**：
- 基线窗口：过去 2-3 年的信号数据
- 检测窗口：最近 1-3 个月
- 滚动检测，跟踪 p-value 的时间序列

#### 方法二：信号自相关衰减

**用途**：测量信号排名的持续性和稳定性。

**原理**（Factor Decay Lab, R² > 0.94）：

```
计算信号值排名的 1阶/5阶/20阶 自相关系数
自相关快速下降 → 信号不稳定，半衰期短
自相关持续下降趋势 → 因子可能即将失效
```

**预警规则**：
- 1 阶自相关 < 0.7 且持续下降 → 信号稳定性恶化
- 20 阶自相关趋近于 0 → 信号在一个月内完全重置

#### 方法三：JSD 散度（Jensen-Shannon Divergence）

**用途**：量化分布差异的幅度（比 KS 检验更稳定，对称有界 [0, 1]）。

```
JSD(P || Q) = ½ D_KL(P || M) + ½ D_KL(Q || M)
其中 M = ½ (P + Q)，D_KL 为 KL 散度
```

**优势**：
- 对称性：JSD(P||Q) = JSD(Q||P)
- 有界性：输出 0 到 1（以 2 为底），便于设定阈值
- 免疫除零问题（KL 散度的主要缺陷）

#### 方法四：Wasserstein 距离

**用途**：量化「把一个分布变成另一个需要多大代价」，直观理解分布漂移的幅度。

```
W(P, Q) = ∫|F_P^{-1}(u) - F_Q^{-1}(u)| du
```

**参考阈值**（SSRN 2024）：Wasserstein 距离 > 40 表明状态发生显著切换。

### 3.4 漂移检测流程

```
输入：信号值时间序列
    │
    ├─→ ① 滑动窗口划分
    │     - 基线窗口：过去 2 年
    │     - 检测窗口：最近 1 个月
    │
    ├─→ ② 多方法联合检测
    │     - KS 检验 → p-value
    │     - 自相关 → 衰减曲线
    │     - JSD → 散度值
    │
    ├─→ ③ 漂移分类
    │     - 分布漂移 + IC 不变 → 协变量偏移（可逆）
    │     - 分布漂移 + IC 下降 → 概念漂移（因子真正失效）
    │     - 无分布漂移 + IC 下降 → 样本内过拟合暴露
    │
    └─→ ④ 输出
          - 漂移报警（阈值告警）
          - 漂移趋势图（时间序列）
          - 漂移归因（哪些维度/行业的信号漂移最大）
```

### 3.5 信号分布特征监控

| 指标 | 计算方式 | 异常信号 |
|------|---------|---------|
| 均值漂移 | 近期均值 vs 历史均值 | 偏离 > 2σ |
| 标准差变化 | 近期标准差 vs 历史标准差 | 变化 > 50% |
| 偏度变化 | 近期偏度 vs 历史偏度 | 符号反转 |
| 峰度变化 | 近期峰度 vs 历史峰度 | 显著上升（厚尾） |
| 覆盖率 | 有效信号覆盖的股票比例 | 下降 > 20% |
| 极值比例 | 超过 ±3σ 的信号占比 | 显著偏离正常水平 |

## 四、信号半衰期估计

### 4.1 定义

半衰期 = 信号排名自相关降至 0.5 所需的时间跨度。

### 4.2 方法：Rank Autocorrelation（置信度最高的方法，Factor Decay Lab）

```python
# 伪代码
def estimate_half_life(signal_df):
    """通过排名自相关估计信号半衰期"""
    ranks = signal_df.rank(axis=1, pct=True)  # 截面排名
    autocorrs = []
    for lag in [1, 2, 3, 5, 10, 21, 42, 63]:
        corr = ranks.corrwith(ranks.shift(lag)).mean()
        autocorrs.append((lag, corr))
    
    # 拟合衰减曲线，找到自相关 = 0.5 的位置
    half_life = interpolate(autocorrs, target=0.5)
    return half_life
```

### 4.3 诊断规则

- **换仓频率 < 信号半衰期**：信号有足够时间发挥作用（必要条件）
- **换仓频率 > 信号半衰期**：信号在换仓前已失效，策略逻辑存在根本缺陷
- **半衰期持续缩短**：信号加速衰减，因子可能正在被市场快速消化

## 五、信号换手率监控

### 5.1 重要性

信号换手率（Churn Rate）不需未来数据、实时可观测，是最简单的策略健康度指标。

### 5.2 计算

```
Churn = 每期信号排名变化的比例
Churn_daily = |rank_t - rank_{t-1}| 的截面均值
```

### 5.3 预警阈值（Factor Decay Lab 实证）

| Churn 水平 | 结论 |
|-----------|------|
| < 5%/天 | 信号稳定，正常 |
| 5-10%/天 | 中等，需关注 |
| 10-15%/天 | 偏高，检查信号逻辑 |
| > 15%/天 | **所有日换手率 > 15% 的信号在 Factor Decay Lab 回测中均为净亏损** |
