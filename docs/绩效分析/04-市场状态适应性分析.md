# 市场状态适应性分析

## 一、概述

**核心观点**：没有任何策略在所有市场状态下都有效。策略失效往往不是因为逻辑错了，而是适用的市场环境不再存在。

**实证**（Factor Decay Lab + Minimum Regime Performance）：
- 动量因子在正常市场的 IC 为 0.059，但在危机期的 IC 反转为 -0.059
- 高夏普策略（总 SR 0.65）的最差状态夏普可能仅为 0.06
- 如果因子只在一个状态下有效，状态切换就等于因子失效

## 二、架构设计

### 2.1 核心思路：Operator(Factor) → Factor

市场状态划分就是 QuantStudio Factor 框架的标准模式——**算子作用在因子上产出新因子**：

```
基础数据因子                    状态划分算子                 标签因子
(DataFactor / FactorDB)        (SectionOperator)          (Label Factor)
─────────────────────    ×    ──────────────────    =    ──────────────
市场收益 Factor               ThresholdClassify          牛熊状态 Factor
波动率 Factor                 QuantileClassify           波动率状态 Factor
价格 Factor                   HMMClassify                综合状态 Factor
...
```

不需要额外的 Dimension/Method/Classifier 抽象层——**算子本身就是全部**。

## 三、状态划分算子 (`operators.py`)

### 3.1 ThresholdClassify — 阈值法（PointOperator）

逐点映射，不需要截面信息也不需要回溯窗口——纯 `PointOperator`。

```python
from QuantStudio.Factor.FactorOperation import PointOperator, makeFactorOperator

@makeFactorOperator(operator_type="Point", args={"thresholds": [-0.0003, 0.0003], "labels": None})
def threshold_classify(f, idt, iid, x, args):
    """基于固定阈值将连续信号离散化为状态标签。

    逐点映射: 对每个 (时点, ID) 的信号值独立判断，无截面/时序依赖。

    Args:
        x: 信号值，len=1（单ID模式）或 array(shape=(len(iid),))（多ID模式）。
        args.thresholds: 阈值列表，n 个状态需要 n-1 个阈值，升序排列。
        args.labels: 状态标签，长度 = len(thresholds) + 1。

    Example:
        signal = RollingMean(60)(market_return_factor)
        bull_bear = ThresholdClassify(
            thresholds=[-0.0003, 0.0003], labels=["熊市", "震荡", "牛市"]
        )(signal, factor_name="牛熊状态")
    """
    thresholds = args.setdefault("thresholds", [])
    labels = args.setdefault("labels", None)
    if labels is None:
        labels = [f"状态{i}" for i in range(len(thresholds) + 1)]

    result = np.full_like(x, labels[len(thresholds) // 2], dtype=object)
    for i, th in enumerate(thresholds):
        result[x <= th] = labels[i]
    result[x > thresholds[-1]] = labels[-1]
    return result
```

### 3.2 QuantileClassify — 滚动分位数法（TimeOperator）

需要 `LookBack` 窗口来计算当前信号值在历史上的分位数位置——`TimeOperator`。

```python
from QuantStudio.Factor.FactorOperation import TimeOperator

class QuantileClassify(TimeOperator):
    """基于滚动分位数将连续信号离散化为状态标签。

    在指定回溯窗口内计算信号的历史分布，根据当前值所处的分位数位置分配状态。
    适合波动率、流动性等需要相对比较的指标。

    Args:
        lookback: 回溯窗口长度（用于计算分位数的历史数据量）。
        low_pct: 低分位阈值。
        high_pct: 高分位阈值。
        labels: 状态标签列表，默认 ['低位', '中位', '高位']。

    Example:
        vol_signal = RollingStd(20)(daily_return_factor) * sqrt(252)
        vol_regime = QuantileClassify(
            lookback=252, low_pct=0.2, high_pct=0.8,
            labels=["低波", "中波", "高波"],
        )(vol_signal, factor_name="波动率状态")
    """

    class __QS_ArgClass__(TimeOperator.__QS_ArgClass__):
        LookBack: list = [252]  # 固定回溯窗口
        DTMode: str = "单时点"
        IDMode: str = "单ID"

    def __init__(self, lookback=252, low_pct=0.2, high_pct=0.8,
                 labels=None, **kwargs):
        self.low_pct = low_pct
        self.high_pct = high_pct
        self.labels = labels or ['低位', '中位', '高位']
        super().__init__(LookBack=[lookback], **kwargs)

    def calculate(self, f, idt, iid, x, args):
        """x[0]: array(shape=(LookBack+1,)), 末尾为当前值，前面为历史值。"""
        signal_history = x[0]
        current_value = signal_history[-1]
        percentile = (signal_history < current_value).mean()
        if percentile <= self.low_pct:
            return self.labels[0]
        elif percentile >= self.high_pct:
            return self.labels[-1]
        else:
            return self.labels[1]
```

### 3.3 HMMClassify — 隐马尔可夫模型（PanelOperator）

需要全截面 + 全时序的联合建模——`PanelOperator`。HMM 需要在计算前对全量数据拟合模型，利用 `init_compute`/`prepare_compute` 阶段完成训练。

```python
from QuantStudio.Factor.FactorOperation import PanelOperator

class HMMClassify(PanelOperator):
    """基于 HMM 的多维市场状态发现。

    对多个输入因子组成的面板数据联合建模，无监督地发现数据驱动的自然状态。
    模型训练在 prepare_compute 阶段完成，预测在 calculate 中执行。

    Args:
        n_components: 状态数量。
        covariance_type: 协方差类型，默认 'full'。
        random_state: 随机种子。

    Example:
        features = [market_return_signal, volatility_signal, volume_change_signal]
        hmm_regime = HMMClassify(n_components=4)(
            *features, factor_name="HMM市场状态"
        )
    """

    class __QS_ArgClass__(PanelOperator.__QS_ArgClass__):
        DTMode: str = "单时点"

    def __init__(self, n_components=4, covariance_type='full',
                 random_state=42, **kwargs):
        self.n_components = n_components
        self.covariance_type = covariance_type
        self.random_state = random_state
        self._Model = None       # 训练后的 HMM 模型

        返回当前时点的状态标签 array(shape=(len(iid),))。"""
```

### 3.4 使用示例

```python
from QuantStudio.Factor.Factor import DataFactor
from QuantStudio.Factor.FactorOperator import RollingMean, RollingStd
from QSExt.MarketRegime.operators import ThresholdClassify, QuantileClassify, HMMClassify

# ---- 读取标签 ----
```

## 四、状态转换检测 (`transition.py`) ✅ 已实现

状态转换检测消费已产出的标签序列，与划分算子独立。

```python
class BaseTransitionDetector(ABC):
    """状态转换检测器基类。"""

    @abstractmethod
    def detect(self, regime_series: pd.Series, **params) -> pd.DataFrame:
        """检测状态转换点。

        Returns:
            DataFrame with columns: date, from_regime, to_regime
        """
        ...


class CUSUMDetector(BaseTransitionDetector):
    """CUSUM: 检测均值的微小持续偏移，适合首次预警。"""
    def __init__(self, threshold=1.5, drift=0.0): ...

class KSTestDetector(BaseTransitionDetector):
    """KS 检验: 确认两段时期分布是否显著不同，用于统计验证。
    输入为连续信号时执行真正的分布变化检测；
    输入为离散标签时退化为相邻标签变化检测。"""
    def __init__(self, p_threshold=0.05, window=60): ...
```

**第三期**（已实现）：

```
WassersteinDetector — Wasserstein 距离，量化分布变化幅度
DTWDetector         — DTW，在历史中寻找与当前模式最相似的时期
```

**推荐级联使用**：

```
① CUSUM（敏感配置）→ 首次预警
② Wasserstein 距离 → 量化变化幅度（第三期）
③ KS 检验 → 统计验证
④ DTW.find_similar() → 寻找历史类比期（第三期）
```

## 五、策略适应性分析

### 5.1 独立工具类 (`StrategyRegimeAnalyzer`)

消费 label Factor 的 `readData()` 结果，分析策略在不同市场状态下的表现。可脱离框架独立使用。

```python
class StrategyRegimeAnalyzer:
    """策略市场状态适应性分析器。

    Args:
        strategy_returns: 策略日收益 Series。
        regime_labels: (日期 × 状态维度) 的标签 DataFrame，
                       来自 label Factor 的 readData() 结果。
    """

    def __init__(self, strategy_returns: pd.Series, regime_labels: pd.DataFrame): ...

    def compute_regime_performance(self, dimension: str = None) -> pd.DataFrame:
        """各状态下的策略表现：年化收益 / 波动 / 夏普 / 最大回撤 / 胜率 / 占比。"""

    def compute_adaptation_heatmap(self, dimension: str, freq: str = 'Q') -> pd.DataFrame:
        """状态 × 时间段的超额收益热力图。"""

    def compute_mrp(self, dimension: str = None) -> dict:
        """Minimum Regime Performance: 最差状态的夏普比率。
        来源：JPM "Measuring Strategy-Decay Risk"
        MRP < 0 → 存在策略确定性亏损的市场状态。"""

    def transition_impact_analysis(self, dimension: str, detector: BaseTransitionDetector = None,
                                    windows: list[int] = [5, 10, 20]) -> dict:
        """状态转换冲击分析：转换期收益 / 方向敏感性 / 转换亏损占比。✅ 已实现

        Returns:
            dict: transitions (转换点明细) / window_returns (各窗口期收益)
                  / direction_impact (方向敏感性) / transition_loss_ratio (转换亏损占比)
        """
```

### 5.2 BTNode 报告节点 (`RegimePerformanceReport`) ✅ 已实现

将 `StrategyRegimeAnalyzer` 包装为 `BTNode`，接入回测计算图。

```python
class RegimePerformanceReport(BTNode):
    """市场状态适应性分析报告（BTNode）。

    Args:
        nv: 策略净值 Factor（如 CalcPortfolioNV 的输出），取第一列计算日收益率。
        regime_label: 市场状态标签 Factor（如 ThresholdClassify / QuantileClassify 的输出）。
        args: 参数集，支持 ``GenReport``、``HeatmapFreq``、``Dimension``、
            ``TransitionDetector``（可选值: ``"default"`` / ``"CUSUM"`` / ``"KS"``）。
    """

    class __QS_ArgClass__(BTNode.__QS_ArgClass__):
        Name: str = "状态适应性分析"
        HeatmapFreq: str = "Q"      # 热力图频率: M/Q/Y
        Dimension: str = None        # 状态维度名（多维度时指定）
        TransitionDetector: str = "default"  # 转换检测器: default / CUSUM / KS

    def __init__(self, nv: Factor, regime_label: Factor, args={}, ...):
        super().__init__(deps=[nv, regime_label], ...)

    def backward_compute(self, path, bwd_data_list, context, local_context=None) -> dict:
        """提取净值和标签数据，调用 StrategyRegimeAnalyzer，返回 Output dict。

        Output:
            "各状态表现": DataFrame   # index=状态名, columns=[占比/年化收益/年化波动/夏普/最大回撤/胜率]
            "适应性热力图": DataFrame # index=状态名, columns=时间段, values=年化收益
            "MRP": DataFrame          # MRP 摘要
            "各状态夏普": DataFrame   # 各状态的夏普比率
            "转换冲击": dict          # transitions / window_returns / direction_impact / transition_loss_ratio
        """
        ...

    def genReport(self, output: dict) -> str:
        """生成 HTML 报告：状态表现柱状图 + 适应性热力图 + MRP 表 + 转换冲击分析。"""
        ...
```
