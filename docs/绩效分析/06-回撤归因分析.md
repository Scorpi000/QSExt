# 回撤归因分析

## 一、概述

回撤是策略失效最直观的体现。回撤归因分析回答两个问题：
1. **什么导致了这次回撤？**（多维度分解）
2. **这次回撤与历史上的哪次相似？**（模式匹配与恢复路径预测）

## 三、回撤多维度归因

### 3.1 个券层面归因

**目的**：找出回撤期贡献最大亏损的具体持仓。

```python
def security_contribution(holdings, returns, drawdown_period):
    """个券层面回撤归因"""
    
    contribution = pd.DataFrame({
        '证券代码': holdings.columns,
        '平均权重': holdings[drawdown_period].mean(),
        '期间收益': returns[drawdown_period].mean(),
        '收益贡献': holdings[drawdown_period].mean() * returns[drawdown_period].mean(),
    }).sort_values('收益贡献')
    
    # Top 10 亏损贡献
    return contribution.head(10)
```

**诊断要点**：
- 亏损集中在少数重仓股 → 集中度风险
- 大量持仓都亏损 → 系统性/因子层面问题
- 高权重 + 低亏损 vs 低权重 + 高亏损 → 区分不同问题类型

### 3.2 行业层面归因

| 指标 | 计算方式 |
|------|---------|
| 行业配置超额 | 策略行业权重 - 基准行业权重 |
| 行业收益贡献 | 行业配置超额 × 行业收益 |
| 行业内选股收益 | 行业内策略收益 - 行业基准收益 |

### 3.3 因子层面归因

**方法**：用 Barra 风格因子对回撤期收益做归因。

```
回撤期总收益 = Σ(因子暴露_i × 因子回撤期收益_i) + 残差回撤
```

**诊断要点**：
- 哪个风格因子的贡献最负 → 该风格暴露是回撤元凶
- 残差回撤占比大 → Alpha 层面的问题，不是 Beta 问题
- 多个因子同时负贡献 → 市场系统性风格切换

### 3.4 信号层面归因

**方法**：计算回撤期内的信号 IC。

```
若回撤期 IC 持续为负 → 信号在回撤期完全反向预测
若回撤期 IC 维持正常 → 收益回撤来自其他原因（执行、流动性等）
```

## 四、回撤模式聚类

### 4.1 回撤特征向量

对每次大回撤提取特征，构建回撤特征库：

| 特征 | 维度 |
|------|------|
| 市场状态 | 回撤开始时的牛熊/波动/风格状态 |
| 行业暴露 | 回撤期的行业超低配向量 |
| 因子暴露 | 回撤期的风格因子暴露向量 |
| 信号 IC | 回撤期各因子的 IC 水平 |
| 流动性 | 回撤期的市场成交量和换手率 |
| 集中度 | 回撤期的持仓 HHI 指数 |

## 五、回撤预警信号

### 5.1 事前预警指标

基于 A 股历史回撤规律，以下指标在回撤前出现异常：

| 预警指标 | 领先时间 | 可靠性 |
|---------|---------|--------|
| 信号 IC 持续下降 | 3-6 个月 | ★★★ 高 |
| 收益相关性拥挤度上升 | 1-3 个月 | ★★★ 高 |
| 持仓集中度上升 | 1-2 个月 | ★★ 中 |
| 信号换手率异常 | 数周 | ★★ 中 |
| 市值因子超额强势 + 拥挤 | 数周 | ★★ 中 |

### 5.2 预警规则

```python
def drawdown_early_warning(signals):
    """回撤早期预警"""
    warnings = []
    
    # IC 持续下降
    if signals['rolling_ic'].iloc[-60:].mean() < 0.02:
        warnings.append(('IC', 'orange', '信号 IC 连续 3 个月低于 0.02'))
    
    # 拥挤度上升
    if signals['correlation_crowding'].iloc[-1] > signals['correlation_crowding'].quantile(0.95):
        warnings.append(('拥挤度', 'red', '收益相关性拥挤度达到 5 年 95% 分位'))
    
    # 持仓集中度
    if signals['hhi'].iloc[-1] > signals['hhi'].rolling(252).mean() + 2 * signals['hhi'].rolling(252).std():
        warnings.append(('集中度', 'orange', '持仓集中度异常上升'))
    
    return warnings
```
