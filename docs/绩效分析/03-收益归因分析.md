# 收益归因分析

## 一、概述

收益归因回答"策略的收益从哪来"——区分真正的选股能力（Alpha）与市场/风格暴露（Beta）的贡献。当策略收益下滑时，归因能帮助判断是 Beta 不再有利还是 Alpha 正在衰减。

## 二、Brinson 收益归因

### 2.1 核心思想

将策略相对于基准的超额收益分解为三部分：

```
超额收益 = 配置效应 + 选股效应 + 交互效应
```

### 2.2 Brinson-Hood-Beebower (BHB) 模型

**适用场景**：选股策略、行业轮动策略。

**公式**：

```
配置效应(j) = (w_p,j − w_b,j) × r_b,j
选股效应(j) = w_b,j × (r_p,j − r_b,j)
交互效应(j) = (w_p,j − w_b,j) × (r_p,j − r_b,j)
```

其中：
- `w_p,j, w_b,j` = 策略和基准在行业/板块 j 中的权重
- `r_p,j, r_b,j` = 策略和基准在行业/板块 j 中的收益率

### 2.3 Brinson-Fachler 变体

**改进**：配置效应中使用行业超额收益（相对总基准），更准确反映超低配决策。

```
配置效应(j) = (w_p,j − w_b,j) × (r_b,j − r_b)
```

**建议**：优选 Brinson-Fachler，配置效应的解释更符合投资直觉。

### 2.4 多期平滑链接

单期 Brinson 在多期累积时会因复利效应产生偏差。常用链接方法：

| 方法 | 特点 | 推荐度 |
|------|------|--------|
| Cariño 对数平滑 | 计算简单，通用性好 | ★★★ |
| Menchero 优化链接 | 误差最小 | ★★★ |
| GRAP 因子链接 | 处理极端权重变化 | ★★ |
| Frongello 递归 | 适合少量时期 | ★★ |

### 2.5 诊断要点

| 情景 | 含义 | 优化方向 |
|------|------|---------|
| 选股效应持续为正，配置效应为负 | 选股能力好但行业配置拖累 | 强化行业中性约束 |
| 选股效应持续为负，配置效应为正 | 行业择时好但选股能力弱 | 行业 ETF 轮动可能更合适 |
| 两者均为负 | 策略系统性失效 | 从信号质量开始排查 |
| 交互效应持续很大 | 策略存在明显的复合效应 | 考虑分解策略逻辑 |

### 2.6 实现参考

Python 库 `pybrinson`（零依赖）已实现所有主流 Brinson 方法，可直接使用。

## 三、Barra 风格因子归因

### 3.1 核心思想

基于 Barra CNE6 风险模型，将策略收益拆解为四级：

```
策略收益 = 市场收益 + 行业收益 + 风格收益 + 残差收益(Alpha)
```

### 3.2 CNE6 风格因子（适用于 A 股）

| 因子类别 | 包含的具体因子 |
|---------|-------------|
| **市场** | Beta |
| **规模** | Size（市值）、MidCap（中市值）、NonLinearSize（非线性市值） |
| **价值** | BTOP（账面市值比）、EarningsYield（盈利收益率） |
| **动量** | Momentum、IndustryMomentum（行业动量） |
| **波动率** | ResidualVolatility（残差波动率）、Beta |
| **流动性** | Liquidity |
| **质量** | Quality、Profitability、Growth、Leverage |
| **情绪** | AnalystSentiment（分析师情绪） |
| **反转** | ShortTermReversal（短期反转） |

### 3.3 归因方法

**方式一：时间序列回归**（简单，推荐先实现）

```python
# 对策略日收益做时间序列回归
import statsmodels.api as sm

y = strategy_daily_returns - risk_free_rate  # 超额收益
X = factor_daily_returns  # 因子日收益矩阵（市场 + 行业 + 风格）

model = sm.OLS(y, X).fit()
# model.params → 各因子的暴露（beta）
# 因子贡献 = beta × factor_return
# model.resid → 残差收益（Alpha）
```

### 3.4 核心诊断指标

| 诊断内容 | 方法 | 预警信号 |
|---------|------|---------|
| **风格暴露漂移** | 滚动计算因子暴露，绘制时间序列 | 某因子暴露从 0 → 0.5σ（如模型不知不觉偏向小盘） |
| **风格收益掩盖 Alpha** | 对比风格收益 vs 残差收益的趋势 | 残差收益持续走弱，但风格收益走强（2021-2024 A 股典型现象） |
| **因子暴露集中度** | 计算各因子暴露的绝对值占比 | 单一因子暴露超过 50% |
| **Alpha 显著性** | FM 回归 t 统计量 | t < 1.96，Alpha 不显著 |

### 3.5 A 股特殊关注点（MSCI / 国君 2024）

- **市值因子非线性**：2017 年前小盘溢价是 Alpha，之后变成了风险因子
- **小市值拥挤**：2023 年底微盘股拥挤度达到 5 年峰值 → 2024 年初崩塌
- **残差 Alpha 衰减**：2021 H2 以来 A 股量化策略的残差收益持续走弱
- **非线性市值（NonLinearSize）**：中盘股与大小盘股的相对表现，对 A 股特别重要

## 四、逐日收益归因

### 4.1 目的

将每天的策略收益分解到持仓层面，找出收益/亏损的具体来源。

### 4.2 分解维度

```
日收益 = Σ 个券贡献
个券贡献 = 个券权重 × 个券日收益

可进一步按行业、因子暴露分组汇总
```

### 4.3 极端日分析

- 筛选收益最差的 5% 交易日
- 分析这些日子的共同特征：持仓结构、行业分布、因子暴露
- 判断是系统性风险还是策略逻辑缺陷

### 4.4 收益贡献集中度

```
HHI_contribution = Σ (个券收益贡献 / 总收益)²

HHI 过高 → 收益集中在少数个券上，策略不够分散
```
