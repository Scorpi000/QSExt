# 因子评测模块标准化方案

> 基于 [因子挖掘方案 v1](./因子挖掘方案_v1.md) 第五章的设计，因子评测模块的详细实现方案。
>
> 最后更新：2026-07-06

---

## 一、设计原则

1. **复用 QuantStudio 计算框架**：评测算子继承 QuantStudio 的 `PanelOperator` / `BTNode` 体系，通过 `Engine` 驱动执行
2. **复用 QSExt 报告框架**：报告生成基于 `ReportGenerator` 组件化架构（Chart / DataTable / StatGrid）
3. **评测逻辑内聚在 QSExt**：所有新增评测算子、评分算法、决策规则均实现在 `QSExt/LLMFactor/evaluation/` 下，不修改 QuantStudio 和 QSExt 的代码
4. **与挖掘日志库集成**：评测结果直接写入 `MiningLogDB`，形成闭环

### 3.3.1 缓存层（FeatherFactorCache）

评测阶段支持 `FeatherFactorCache` 缓存因子计算结果，避免重复查询数据库。

**配置**（`evaluation.yaml`）：

```yaml
cache_enabled: true               # 启用缓存
cache_dir: null                   # null = 使用系统临时目录，指定固定路径可跨次复用
cache_start_mode: "continue"     # "continue" 复用已有缓存，"new" 每次清空
```

**使用方式**：

```python
from QSExt.LLMFactor.evaluation.cache_manager import EvalCacheManager

# 外部管理 Cache（推荐用于多轮评测）
cache_manager = EvalCacheManager(cache_dir=config.cache_dir, start_mode=config.cache_start_mode)
cache = cache_manager.get_or_create(dt_ruler)

# 传递给 evaluator，IS/OOS 共享同一 Cache
evaluator.evaluate(..., cache=cache)

# 关闭时持久化状态到 state.pkl
cache_manager.close()
```

**降级行为**：当 `start_mode="continue"` 且 `state.pkl` 不存在时，Cache 内部自动降级为 `new` 模式并给出警告。

## 四、新增评测算子详细设计

### 4.1 组合增量 IC 检验（方案 5.5 节核心）

**文件**：`operators/incremental_ic.py`

**算法**：双残差法（来自 `[[dual-residual-incremental-ic]]`）

```
输入：
  - candidate_factor: 候选因子截面值
  - returns: 未来收益率
  - base_factors: 基准因子池（已有入库因子）

步骤：
  1. 将候选因子对基准因子池做 OLS 回归，取残差 ε_f
  2. 将未来收益对基准因子池做 OLS 回归，取残差 ε_r
  3. 计算 ε_f 与 ε_r 的截面相关系数 → 即增量 IC

输出：
  - IncrementalIC: 增量 IC 时间序列
  - MaxCorrelation: 与已有因子的最大相关性（仅参考）
  - Breadth: 截面宽度
```

**算子接口**：


### 4.2 规模分层 Alpha 检验（方案 5.3 节 Part 4）

**文件**：`operators/size_stratified.py`

**算法**：

```
输入：
  - factor: 候选因子
  - market_cap: 市值因子
  - price: 价格因子
  - risk_factors: 风险因子（Fama-French）

步骤：
  1. 按市值将股票分为 5 组（每期截面分组）
  2. 每组内独立构造多空组合（Top 20% vs Bottom 20%）
  3. 对每组多空组合收益做 CAPM / FF3 回归
  4. 提取各组的 Alpha 和 t 统计量

输出：
  - 各组的 Alpha、t 统计量、年化收益、Sharpe
```

## 五、五维度评分

**文件**：`scoring.py`

### 5.1 评分模型

```python
@dataclass
class FiveDimScore:
    """五维度综合评分（每个维度 0-1）。"""
    effectiveness: float      # 有效性 — RankIC 均值 + ICIR
    stability: float          # 稳定性 — IC 时序特征
    turnover: float           # 换手率 — 交易成本代理
    diversity: float          # 多样性 — 增量 IC 显著性
    overfitting_risk: float   # 过拟合风险 — IS/OOS 衰减比 + LLM 评估
    composite: float          # 综合得分 — 加权平均

    def __post_init__(self):
        if self.composite == 0:
            self.composite = (
                0.25 * self.effectiveness +
                0.20 * self.stability +
                0.15 * self.turnover +
                0.20 * self.diversity +
                0.20 * self.overfitting_risk
            )
```

### 5.2 各维度计算

**有效性**（effectiveness）：

```python
def calc_effectiveness(rankic_mean: float, icir: float) -> float:
    """RankIC 均值和 ICIR 的归一化。
    - RankIC: 0.02 → 0.5, 0.06 → 1.0
    - ICIR: 0.3 → 0.5, 0.8 → 1.0
    """
    ic_score = np.clip((rankic_mean - 0.01) / 0.05, 0, 1)
    ir_score = np.clip((icir - 0.1) / 0.7, 0, 1)
    return 0.6 * ic_score + 0.4 * ir_score
```

**稳定性**（stability）：

```python
def calc_stability(ic_series: pd.Series) -> float:
    """IC 时序特征。
    - 胜率（IC > 0 的比例）
    - IC 的自相关性（高自相关 → 更稳定）
    """
    win_rate = (ic_series > 0).mean()
    autocorr = ic_series.autocorr(lag=1) if len(ic_series) > 2 else 0
    win_score = np.clip((win_rate - 0.4) / 0.3, 0, 1)
    stab_score = np.clip((autocorr + 0.5) / 1.0, 0, 1)
    return 0.6 * win_score + 0.4 * stab_score
```

**换手率**（turnover）：

```python
def calc_turnover(avg_turnover: float) -> float:
    """低换手更好。
    - 换手率 0.3 → 1.0, 0.8 → 0.2
    """
    return np.clip(1.0 - (avg_turnover - 0.2) / 0.8, 0, 1)
```

**多样性**（diversity）：

```python
def calc_diversity(incremental_ic_t: float, max_correlation: float) -> float:
    """增量 IC 显著性 + 相关性惩罚。
    - 增量 IC t 统计量归一化
    - 相关性连续折价：(1 - MaxCorr * 0.3)
    """
    ic_score = np.clip((abs(incremental_ic_t) - 1.0) / 3.0, 0, 1)
    corr_penalty = 1.0 - max_correlation * 0.3
    return ic_score * corr_penalty
```

**过拟合风险**（overfitting_risk）：

```python
def calc_overfitting_risk(
    is_rankic: float, oos_rankic: float,
    is_icir: float, oos_icir: float,
    factor_code: str = "",
    refinement_history: list = None,
) -> float:
    """低风险 → 高分。
    - 量化：IS/OOS 衰减比（> 0.7 → 低风险, < 0.3 → 高风险）
    - 定性：LLM 评估（可选，T=0.1）
    """
    ic_decay = oos_rankic / is_rankic if is_rankic > 0 else 0.5
    ir_decay = oos_icir / is_icir if is_icir > 0 else 0.5
    decay_score = np.clip((ic_decay - 0.3) / 0.5, 0, 1) * 0.5 + \
                  np.clip((ir_decay - 0.3) / 0.5, 0, 1) * 0.5

    llm_score = 0.5  # 默认中性
    if factor_code:
        llm_score = _llm_overfitting_assessment(factor_code, refinement_history)

    return 0.6 * decay_score + 0.4 * llm_score
```

## 六、入库决策

**文件**：`decision.py`

### 6.1 决策模型

```python
@dataclass
class DecisionResult:
    """入库决策结果。"""
    decision: str           # "accepted" / "refining" / "rejected"
    reason: str             # 决策原因摘要
    checks: dict[str, dict]  # 各项检查详情

    @property
    def factor_type(self) -> str:
        """因子类型：standard / synergistic。"""
        if self.checks.get("oos_rankic", {}).get("synergistic", False):
            return "synergistic"
        return "standard"
```

### 6.2 决策规则

对应方案文档 5.5 节的三态决策：

```python
def make_decision(
    ic_stats: dict,
    oos_ic_stats: dict,
    incremental_ic_stats: dict,
    scores: FiveDimScore,
    alpha_stats: dict,
    config: EvalConfig,
) -> DecisionResult:
    """入库决策（三态）。

    必要条件（全部满足 → accepted）：
    1. 至少一个 Alpha 检验 t > 3.0
    2. 五维度综合评分 > 0.60
    3. 组合增量 IC 显著（t > 2.0）← 多样性主关卡
    4. OOS RankIC > 0.02 或增量 IC 显著（协同型例外）
    """
    checks = {}

    # 检查 1: Alpha t > 3.0
    alpha_ok = alpha_stats["max_t"] > config.min_alpha_t
    checks["alpha_t"] = {
        "passed": alpha_ok,
        "value": alpha_stats["max_t"],
        "threshold": config.min_alpha_t,
    }

    # 检查 2: 综合评分 > 0.60
    score_ok = scores.composite >= config.min_composite_score
    checks["composite_score"] = {
        "passed": score_ok,
        "value": scores.composite,
        "threshold": config.min_composite_score,
    }

    # 检查 3: 增量 IC t > 2.0（多样性主关卡）
    inc_ok = abs(incremental_ic_stats["t_stat"]) >= config.min_incremental_ic_t
    checks["incremental_ic_t"] = {
        "passed": inc_ok,
        "value": incremental_ic_stats["t_stat"],
        "threshold": config.min_incremental_ic_t,
    }

    # 检查 4: OOS RankIC > 0.02 或增量 IC 显著（协同型例外）
    oos_ok = abs(oos_ic_stats["rankic_mean"]) >= config.min_oos_rankic
    synergistic = not oos_ok and inc_ok
    checks["oos_rankic"] = {
        "passed": oos_ok or synergistic,
        "value": oos_ic_stats["rankic_mean"],
        "threshold": config.min_oos_rankic,
        "synergistic": synergistic,
    }

    # 决策
    all_passed = all(c["passed"] for c in checks.values())
    if all_passed:
        return DecisionResult("accepted", _build_accept_reason(checks), checks)
    elif any([alpha_ok, score_ok]):
        return DecisionResult("refining", _build_refine_reason(checks), checks)
    else:
        return DecisionResult("rejected", _build_reject_reason(checks), checks)
```

### 6.3 相关性预警

相关性仅作预警信号，不作为硬门槛（方案 v1 核心修订）：

```python
def check_correlation_warning(
    max_correlation: float,
    config: EvalConfig,
) -> dict:
    """相关性预警检查。超过阈值 → 触发增量 IC 复核，而非直接拒绝。"""
    if max_correlation > config.corr_warning_threshold:
        return {
            "warning": True,
            "message": f"与已有因子最大相关性 {max_correlation:.2f} 超过预警阈值 "
                       f"{config.corr_warning_threshold}，需复核增量 IC",
        }
    return {"warning": False}
```

### 7.1 报告数据准备

```python
def prepare_report_data(
    ic_output: dict,
    ic_decay_output: dict,
    portfolio_output: dict,
    turnover_output: dict,
    incremental_ic_output: dict,
    size_stratified_output: dict,
    sub_period_output: dict,
    scores: FiveDimScore,
    decision: DecisionResult,
) -> DataContext:
    """将评测算子输出组织为 DataContext。"""
    ctx = DataContext(output={}, factor_names=[], config={})

    # 模块数据（与 QuantStudio BTReport 输出对齐）
    ctx.set("0-Rank IC 分析", "IC", ic_output["IC"])
    ctx.set("0-Rank IC 分析", "统计数据", ic_output["统计数据"])
    ctx.set("1-IC 衰减分析", "IC衰减", ic_decay_output["IC"])
    ctx.set("1-IC 衰减分析", "统计数据", ic_decay_output["统计数据"])
    ctx.set("2-分位数组合", "净值", portfolio_output["净值"])
    ctx.set("2-分位数组合", "超额净值", portfolio_output["超额净值"])
    ctx.set("2-分位数组合", "统计数据", portfolio_output["统计数据"])
    ctx.set("3-因子换手率", "换手率", turnover_output["换手率"])

    # 新增模块数据
    ctx.set("4-增量IC检验", "IC", incremental_ic_output["IC"])
    ctx.set("4-增量IC检验", "统计数据", incremental_ic_output["统计数据"])
    ctx.set("5-规模分层", "统计数据", size_stratified_output["统计数据"])
    ctx.set("5-规模分层", "净值", size_stratified_output["净值"])
    ctx.set("6-子期稳健性", "统计数据", sub_period_output["统计数据"])

    # 评分和决策
    ctx.set("7-五维度评分", "评分", _score_to_dataframe(scores))
    ctx.set("8-入库决策", "决策", _decision_to_dataframe(decision))
    ctx.set("8-入库决策", "检查详情", _checks_to_dataframe(decision.checks))
```

## 八、统一评测入口

**文件**：`evaluator.py`

### 8.1 FactorEvaluator 类

```python
class FactorEvaluator:
    """因子评测器 — 构建并执行 QuantStudio 评测 DAG。

    职责：
    1. 构建 QuantStudio 计算图（IC + 分位数组合 + 增量IC + ...）
    2. 驱动 Engine 执行
    3. 收集结果，调用 scoring 和 decision
    4. 生成报告
    5. 写入 MiningLogDB

    用法：
        evaluator = FactorEvaluator(config)
        report = evaluator.evaluate(
            factor=因子对象,
            price=价格因子,
            mask=筛选条件,
            industry=行业因子,
            market_cap=市值因子,
            base_factors=基准因子池,
            risk_factors=Fama-French因子,
        )
    """

    def __init__(self, config: EvalConfig = None):
        self.config = config or EvalConfig()

    def evaluate(
        self,
        factor,
        price,
        mask=None,
        industry=None,
        market_cap=None,
        base_factors=None,
        risk_factors=None,
        factor_name="",
        category="",
        qsid="",
    ) -> EvalReport:
        """执行完整评测流程。"""
        # Step 1: 构建 DAG
        dag_nodes = self._build_dag(
            factor, price, mask, industry, market_cap,
            base_factors, risk_factors,
        )

        # Step 2: 执行 DAG
        output = self._run_dag(dag_nodes)

        # Step 3: 五维度评分
        scores = calc_scores(
            ic_stats=output["ic_stats"],
            oos_ic_stats=output["oos_ic_stats"],
            portfolio_stats=output["portfolio_stats"],
            incremental_ic_stats=output["incremental_ic_stats"],
            turnover_stats=output["turnover_stats"],
        )

        # Step 4: 入库决策
        decision = make_decision(
            ic_stats=output["ic_stats"],
            oos_ic_stats=output["oos_ic_stats"],
            incremental_ic_stats=output["incremental_ic_stats"],
            scores=scores,
            alpha_stats=output["alpha_stats"],
            config=self.config,
        )

        # Step 5: 生成报告
        report_path = self._generate_report(output, scores, decision, factor_name)

        # Step 6: 写入 MiningLogDB
        if self.config.save_to_mining_log:
            self._save_to_mining_log(output, scores, decision, factor_name, category, qsid)

        return EvalReport(
            factor_name=factor_name,
            qsid=qsid,
            category=category,
            scores=scores,
            decision=decision,
            report_path=report_path,
            raw_output=output,
        )

    def _build_dag(self, factor, price, mask, industry, market_cap,
                   base_factors, risk_factors):
        """构建 QuantStudio 评测 DAG。"""
        # 复用 QuantStudio 现有算子
        from QuantStudio.BackTest.SectionFactor.api import (
            CalcIC, IC, ICDecay, makeQuantilePortfolio, MultiPortfolio,
            CalcFactorTurnover, FactorTurnover,
        )
        from QuantStudio.BackTest.Strategy.AllocationStrategy import CalcPortfolioNV

        # 新增算子（QSExt 实现）
        from QSExt.LLMFactor.evaluation.operators.incremental_ic import CalcIncrementalIC
        from QSExt.LLMFactor.evaluation.operators.size_stratified import CalcSizeStratifiedAlpha
        from QSExt.LLMFactor.evaluation.nodes.incremental_ic_node import IncrementalICNode
        from QSExt.LLMFactor.evaluation.nodes.size_stratified_node import SizeStratifiedAlphaNode

        nodes = {}

        # 1. RankIC
        ic_factor = CalcIC(...) (factor, price=price, mask=mask, cat_data=industry)
        nodes["ic"] = IC(ic_factor, args={"GenReport": True})

        # 2. IC 衰减
        decay_factors = [CalcIC(period_lookback=i, ...) (...) for i in [1,2,3,6,12]]
        nodes["ic_decay"] = ICDecay(ic_list=decay_factors, args={"GenReport": True})

        # 3. 分位数组合
        portfolios = makeQuantilePortfolio(factor, mask=mask, cat_data=industry, ...)
        nv_factors = [CalcPortfolioNV(...) (p, price=price) for p in portfolios]
        nodes["portfolio"] = MultiPortfolio(nv_factors, args={"GenReport": True})

        # 4. 换手率
        turnover = CalcFactorTurnover(...) (factor, mask=mask)
        nodes["turnover"] = FactorTurnover(turnover, args={"GenReport": True})

        # 5. 增量 IC（新增）
        if base_factors:
            inc_ic = CalcIncrementalIC(...) (factor, price=price, base=base_factors, mask=mask)
            nodes["incremental_ic"] = IncrementalICNode(inc_ic, args={"GenReport": True})

        # 6. 规模分层（新增）
        if market_cap:
            size_alpha = CalcSizeStratifiedAlpha(...) (factor, market_cap=market_cap, price=price, ...)
            nodes["size_stratified"] = SizeStratifiedAlphaNode(size_alpha, args={"GenReport": True})

        return nodes

    def _run_dag(self, nodes):
        """执行 DAG，收集输出。"""
        from QuantStudio.BackTest.BackTestModel import BTReport
        from QuantStudio.BackTest.BackTestEngine import Engine

        report_node = BTReport(bt_node_list=list(nodes.values()))
        Engine.run([report_node], dt_range=...)
        return report_node.Output

    def _generate_report(self, output, scores, decision, factor_name):
        """生成报告。"""
        from QSExt.LLMFactor.evaluation.report import prepare_report_data
        from QSExt.ReportGenerator.layout import LayoutRenderer
        from QSExt.ReportGenerator.renderers.html_renderer import HtmlRenderer

        ctx = prepare_report_data(output, scores, decision)
        renderer = LayoutRenderer()
        html = renderer.render(report_config, ctx, theme, fmt="html")

        # 写入文件
        report_path = f"local/workspace/eval_{factor_name}.html"
        with open(report_path, "w", encoding="utf-8") as f:
            f.write(html)
        return report_path

    def _save_to_mining_log(self, output, scores, decision, factor_name, category, qsid):
        """写入挖掘日志库。"""
        from QSExt.LLMFactor.llm.mining_log import MiningLogRepository, MiningLogDB, MiningRun

        db = MiningLogDB()
        repo = MiningLogRepository(db)

        run = MiningRun(id=f"EVAL_{factor_name}_{datetime.now().strftime('%Y%m%d_%H%M%S')}")
        run.metadata["factor_name"] = factor_name
        run.metadata["category"] = category
        run.metadata["qsid"] = qsid
        run.metadata["rankic_mean"] = output["ic_stats"]["rankic_mean"]
        run.metadata["rankicir"] = output["ic_stats"]["icir"]
        run.metadata["incremental_ic"] = output["incremental_ic_stats"]["mean_ic"]
        run.metadata["incremental_ic_t"] = output["incremental_ic_stats"]["t_stat"]
        run.metadata["max_correlation"] = output["incremental_ic_stats"]["max_correlation"]
        run.metadata["composite_score"] = scores.composite
        run.metadata["decision"] = decision.decision
        run.metadata["decision_reason"] = decision.reason
        run.metadata["evaluation"] = output
        run.content = f"因子评测：{factor_name}，决策：{decision.decision}"
        run.tags = [category, decision.decision]

        repo.insert_run(run)
```

### 15.1 三态决策流程

```

                    │   开始评测       │
                    └────────┬────────┘

     └───────┬────────┘     │     └───────┬────────┘
```

### 15.2 检查项说明

| 检查项 | 阈值 | 说明 |
|--------|------|------|
| `alpha_t` | > 3.0 | 至少一个 Alpha 检验（CAPM/FF3/FF5/Carhart）的 t 统计量 |
| `composite_score` | > 0.60 | 五维度综合评分 |
| `incremental_ic_t` | > 2.0 | 组合增量 IC 的 t 统计量（多样性主关卡） |
| `oos_rankic` | > 0.02 | 样本外 RankIC（协同型因子可豁免） |

### 15.3 协同型因子

当候选因子单独 OOS RankIC 不达标（< 0.02），但组合增量 IC 显著（t > 2.0）时，判定为**协同型因子**（`synergistic`）。

协同型因子的特征：
- 单独预测能力弱
- 但与已有因子组合后能提供显著增量信息
- 依据：`[[mutual-ic-vs-synergy-gap]]` 的实验证据

```python
# 协同型因子判定
decision = make_decision(
    ic_stats={"rankic_mean": 0.015, "icir": 0.3, "t_stat": 2.5},
    oos_ic_stats={"rankic_mean": 0.008},  # 低于 0.02 阈值
    incremental_ic_stats={"t_stat": 2.5, "max_correlation": 0.6},  # 增量 IC 显著
    scores=scores,
    alpha_stats={"capm_t": 3.5},
    config=config,
)

print(decision.decision)      # "accepted"
print(decision.factor_type)   # "synergistic"
```
