# FactorDef —— 因子定义模块

FactorDef 是 QSExt 的因子定义框架，提供因子模块的元信息声明、依赖自动解析、运行时配置管理和执行调度。

## 目录结构

```
QSExt/FactorDef/
├── FactorDefContent.py           # 核心类：FactorDefInput / FactorMeta / FactorDef
│                                 #         FactorDBPool / FactorDefSettings / FactorDefInputBuilder
├── utils.py                      # 工具：expand_glob()
├── conf/
│   └── settings_example.py       # 配置文件示例
└── scripts/
    ├── run_factor_def.py                 # 统一执行入口
    └── register_factors_to_graphdb.py    # 图数据库注册
```

因子定义脚本（业务模块）按惯例放在使用项目中，通过 `from QSExt.FactorDef.FactorDefContent import FactorDefInput` 引用框架，通过 `settings.py` 的 `ID_PROFILES` 配置模块路径。

## 核心类

### FactorDefInput — 运行时上下文

传递给 `defFactor(fdi)` 的入参：

| 字段 | 类型 | 说明 |
|------|------|------|
| `FDB` | `Dict[str, FactorDB]` | 可用因子库字典 |
| `DTs` | `List[datetime]` | 计算时点 |
| `DTRuler` | `List[datetime]` | 时点标尺（覆盖全部回溯范围） |
| `IDs` | `List[str]` | 证券 ID 列表 |
| `SectionIDs` | `List[str]` | 截面 ID |
| `ModelArgs` | `Dict` | 模型参数 |
| `Factors` | `Dict[str, Factor]` | 已解析的依赖因子（由框架根据 `FactorDeps` 注入） |

### FactorMeta — 静态元信息

描述因子模块的固有属性，**不依赖数据库连接即可读取**。所有字段均有默认值。

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `TargetTable` | `""` | 输出因子表名 |
| `IDType` | `""` | ID 类型：`"A股"`、`"指数"`、`"ETF"` 等 |
| `Author` | `"Anonymous"` | 作者 |
| `Description` | `""` | 因子描述，用于向量检索 |
| `MaxLookBack` | `365` | 最大回溯天数 |
| `DefaultStartDT` | `2002-01-01` | 默认起始日 |
| `DTType` | `"自定义"` | 时点类型 |
| `Freq` | `"1d"` | 时点频率 |
| `Tags` | `[]` | 检索标签 |
| `FactorDeps` | `{}` | 依赖因子声明：`{表名: [entry, ...]}`，entry 为字符串或字典，详见下方 |
| `DBDeps` | `{}` | 因子库依赖声明：`{FactorDB 逻辑名称: 用途说明}`，框架会校验声明的库是否在 `fdi.FDB` 中存在 |
| `ModelArgs` | `{}` | 期望的模型参数声明：`{参数名: 说明}`，用于文档化和校验 |
| `DefScriptPath` | `""` | 定义脚本路径 |

### FactorDef — 因子定义对象

由框架在 `build_dep_fd` 中自动构造，**模块不需要直接创建**。

```python
# 框架内部构造（模块不参与）
FactorDef(FactorList=factor_list, Meta=FactorMeta(**meta))
```

| 属性/方法 | 说明 |
|-----------|------|
| `FactorList` | `List[Factor]`，动态因子列表 |
| `Meta` | `FactorMeta`，静态元信息 |
| `FactorNames` | 返回所有因子名称 |
| `getFactor(name, ...)` | 按名称/路径查找因子 |

## 运行时配置系统

配置文件是 Python 模块，将数据源、时间范围、模块列表等参数从脚本中分离。

**合并优先级**（由低到高）：
1. `settings.py` 配置模块
2. `settings_local.py`（不入库）
3. `FACTORDEF_*` 环境变量
4. 命令行 `--xxx` 参数

### FactorDBPool — 因子库连接池

统一管理 `FactorDB` 实例的生命周期：

```python
pool = FactorDBPool(settings.factor_databases)
pool.create_all()      # 实例化
pool.connect_all()     # 连接
jydb = pool["JYDB"]    # 按名称访问
pool.disconnect_all()  # 断开
```

每个库通过 dict 定义（settings 中自动转为 `FactorDBDef`）：

| 字段 | 说明 |
|------|------|
| `name` | 逻辑名称 |
| `class` | 类名或完整路径：`"JYDB"` / `"HDF5DB"` / `"QuantStudio.Factor.XXX.XXX"` |
| `role` | `"source"` / `"target"` / `"proxy"` |
| `args` | 构造参数字典 |
| `config_file` | （可选）JSON 配置文件路径 |

### FactorDefSettings — 配置对象

```python
from QSExt.FactorDef.FactorDefContent import FactorDefSettings

settings = FactorDefSettings.from_module("path.to.settings", debug=True)
```

关键字段（对应 `settings.py` 中的大写变量）：

| 字段 | 说明 |
|------|------|
| `factor_databases` | 因子库定义列表 |
| `factor_modules` | 模块列表（完整路径或 glob） |
| `end_dt` | 截止日期，支持 `"today"`、`"last_friday"` |
| `lookback` / `max_lookback` | 回溯天数 |
| `dt_source` / `id_source` | 提供交易日/股票列表的库名 |
| `target_db` | 输出目标库名 |
| `workers` | 并发 worker 数 |
| `debug` | 调试模式（只取 3 只股票） |

### FactorDefInputBuilder — 装配器

根据配置构造 `FactorDefInput`，管理完整生命周期：

```python
from QSExt.FactorDef.FactorDefContent import FactorDefInputBuilder

with FactorDefInputBuilder(settings) as builder:
    fdi = builder.build()               # 组装 FactorDefInput
    modules = builder.resolve_modules() # 解析模块列表（含 glob 展开）
    # ... 运行因子定义 ...
# 退出 with 时自动断开所有因子库
```

### 模块命名规范

模块通过**完整 Python 导入路径**指定，支持 glob 模式：

```python
# 完整路径
"your_project.factor_defs.stock_cn_factor_value"

# glob 模式（fnmatch 匹配，内部用 pkgutil.iter_modules 展开）
"your_project.factor_defs.stock_cn_*"      # 所有 A 股因子
"your_project.factor_defs.stock_hk_*"      # 所有港股因子
```

两种形式可混合：

```python
ID_PROFILES = [
    {"id_type": "A股", "factor_modules": [
        "your_project.factor_defs.stock_cn_status",
        "your_project.factor_defs.stock_cn_*",
    ]},
]
```

glob 展开工具：

```python
from QSExt.FactorDef.utils import expand_glob
expand_glob("your_project.factor_defs.stock_cn_*")
# → ['your_project.factor_defs.stock_cn_status', 'your_project.factor_defs.stock_cn_industry', ...]
```

def init_db(pool):

## `__FACTOR_META__` 约定

每个因子模块在顶部声明 `__FACTOR_META__` 字典，作为元信息的唯一来源。

| 字段 | 必填 | 说明 |
|------|------|------|
| `TargetTable` | 是 | 输出因子表名 |
| `IDType` | 是 | ID 类型标识 |
| `Description` | 是 | 一句话描述 |
| `Author` | 否 | 默认 `"Anonymous"` |
| `MaxLookBack` | 否 | 默认 365 |
| `Tags` | 否 | 检索标签列表 |
| `FactorDeps` | 否 | 依赖因子声明：`{表名: [因子名列表]}`，详见下方 |
| `DBDeps` | 否 | 依赖的因子库声明：`{"JYDB": "说明"}`，键为 `fdi.FDB` 中的逻辑名称，值为用途说明。默认为 `{}` |
| `ModelArgs` | 否 | 期望的模型参数声明：`{参数名: 说明}`，详见下方 |
| `DefScriptPath` | 否 | 定义脚本路径（通常填 `__file__`） |

### DBDeps 说明

声明模块直接访问的因子库（通过 `fdi.FDB["库名"]`），框架做前置校验和依赖追踪：

```python
# 直接使用因子库
"DBDeps": {"JYDB": "聚源数据库，提供行情和财务数据"}

# 使用多个因子库
"DBDeps": {
    "JYDB": "聚源数据库，提供 ETF 申赎清单等数据",
    "LDB": "本地因子库，提供已计算的个股日行情因子",
}
```

框架在执行模块前会校验声明的库名是否在 `fdi.FDB` 中存在，不存在时抛出 `KeyError`。

### ModelArgs 声明

当 `defFactor` 需要参数时，在 `__FACTOR_META__` 中声明：

```python
__FACTOR_META__ = {
    "TargetTable": "stock_cn_index_component",
    "ModelArgs": {
        "constituent_index_list": "指数成份列表 DataFrame",
        "weight_index_list": "指数成份权重列表 DataFrame",
    },
    ...
}
```

作用：
- **自文档化**：阅读 `__FACTOR_META__` 即可知道模块需要哪些参数
- **前置校验**：框架检查 `FactorDeps` 中的 `$` 引用是否在 `ModelArgs` 中声明

### FactorDeps 格式

```python
"FactorDeps": {
    "依赖表名": [
        "因子名",                                          # 直接取因子
        "*",                                               # 该表全部因子
        "$model_args_key",                                 # $ 前缀：从 ModelArgs 动态取因子名
        {"Name": "orig_name", "Alias": "alias"},           # 取因子并重命名
        {"Name": "*", "ModelArgs": {"key": "$parent_key"}},# 传递 ModelArgs 给依赖模块
    ],
}
```

**两种 entry 格式**：

| 格式 | 说明 |
|------|------|
| 字符串 `"close"` | 按名称取因子，`"*"` 取全部因子，`$` 前缀从 `ModelArgs` 取真实名 |
| 字典 `{"Name": "...", ...}` | Name 必填（`"*"` 表示全部），Alias（可选）重命名，ModelArgs（可选）传递给依赖模块的 `defFactor` |

**ModelArgs 传递机制**：

```python
__FACTOR_META__ = {
    "FactorDeps": {
        "stock_cn_index_component": [
            {"Name": "*", "ModelArgs": {
                "constituent_index_list": "$constituent_index_list",
                "weight_index_list": "$weight_index_list",
            }},
        ],
        "stock_cn_status": ["if_listed"],
    },
}
```

`$constituent_index_list` 从当前 `fdi.ModelArgs` 中查找并透传给依赖模块。

## defFactor 规范

所有因子模块使用统一签名：

```python
from QSExt.FactorDef.FactorDefContent import FactorDefInput

def defFactor(fdi: FactorDefInput) -> list:
    ...
```

| 参数 | 说明 |
|------|------|
| `fdi` | 运行时上下文，包含 `FDB`、`DTs`、`IDs`、`ModelArgs`、`Factors` |
| 返回值 | `List[Factor]` — 框架自动包装为 `FactorDef` |

### build_dep_fd —— 依赖自动解析

递归解析 `__FACTOR_META__["FactorDeps"]`，自动发现并执行依赖模块，将依赖因子注入 `fdi.Factors`：

```python
from QSExt.FactorDef.FactorDefContent import build_dep_fd

# 不使用代理
FactorDefDict, factor_defs = build_dep_fd(modules, fdi)

# 使用代理
FactorDefDict, factor_defs = build_dep_fd(
    modules, fdi,
    proxy_db=proxy_db,
    proxy_table_mapping=proxy_table_mapping,
    proxy_tables=proxy_tables,
)
```

依赖名解析规则：
1. 先尝试作为**完整 Python 导入路径**直接 `import`
2. 再尝试拼接**调用者所在包路径**
3. 都不行则报错

## 脚本说明

### run_factor_def.py — 统一执行入口

```bash
# 默认配置
python QSExt/FactorDef/scripts/run_factor_def.py

# 指定配置
python QSExt/FactorDef/scripts/run_factor_def.py --settings settings_prod

# 增量更新
python QSExt/FactorDef/scripts/run_factor_def.py --settings settings_prod --use-proxy

# 命令行覆盖
python QSExt/FactorDef/scripts/run_factor_def.py --debug --end-dt 2026-06-30 --workers 4

# Dry-run
python QSExt/FactorDef/scripts/run_factor_def.py --dry-run
```

| 参数 | 说明 |
|------|------|
| `--settings`, `-s` | 配置模块路径 |
| `--debug`, `-d` | 调试模式 |
| `--dry-run`, `-n` | 仅分析，不执行 |
| `--end-dt` | 截止日期 |
| `--start-dt` | 起始日期 |
| `--lookback` | 回溯天数 |
| `--workers`, `-w` | 并发 worker 数 |
| `--use-proxy` | 使用代理因子库 |
| `--register-graph` | 注册到图数据库 |

### register_factors_to_graphdb.py — 图数据库注册

```bash
python QSExt/FactorDef/scripts/register_factors_to_graphdb.py
python QSExt/FactorDef/scripts/register_factors_to_graphdb.py --settings settings_prod --tags 动量
python QSExt/FactorDef/scripts/register_factors_to_graphdb.py --skip-embedding
```

| 参数 | 说明 |
|------|------|
| `--settings`, `-s` | 配置模块路径 |
| `--modules` | 指定模块 |
| `--tags`, `-t` | 附加标签 |
| `--skip-embedding` | 跳过向量嵌入 |
