# FactorDef v2 设计文档

> **注意**：本文档为历史设计文档，部分实现细节已变更。以 [因子定义.md](因子定义.md) 为准。
> 主要变更：
> - `defFactor` 返回 `List[Factor]`，不再返回 `FactorDef`（框架负责包装）
> - `Dependencies` 字段已废弃，统一使用 `FactorDeps`
> - `dep_fd` 参数已废弃，依赖因子通过 `fdi.Factors` 访问

## 1. 背景与问题

当前 `FactorDef` 类承载了两类职责：

| 职责 | 字段 | 特征 |
|---|---|---|
| **静态元信息** — 描述"这个模块是什么" | TargetTable, IDType, Author, Description, MaxLookBack, ... | 模块固有属性，从不变化 |
| **动态产物** — 描述"这次调用产出了什么" | FactorList, FDI | 每次调用 defFactor 都不同 |

两者混在同一个对象中，导致：

- **发现成本高**：想列出所有可用模块（如 `--dry-run`），必须先连 JYDB → 构造 FactorDefInput → 递归解析依赖链 → 构造数百个因子对象
- **分类信息缺失**：FactorDef 没有 Tags 字段，无法按标签筛选
- **List[Factor] 模式无元信息**：返回裸因子列表的模块完全缺失静态元信息
- **依赖关系隐式**：模块间依赖仅存在于 Python import 中，程序无法获取

## 2. 设计概览

```
┌─────────────────────────────────────────────────────┐
│ __FACTOR_META__ (模块级)                              │
│ ┌─────────────────────────────────────────────────┐ │
│ │ TargetTable, IDType, Author, Description, ...   │ │
│ │ MaxLookBack, DTType, Freq, DefaultStartDT       │ │
│ │ Tags, FactorDeps    ← 新增                      │ │
│ └─────────────────────────────────────────────────┘ │
│              ↓ 构造                                  │
│ ┌─────────────────────────────────────────────────┐ │
│ │ FactorMeta (数据类)     ← 静态元信息             │ │
│ └──────────────┬──────────────────────────────────┘ │
│                │ 作为 Meta 字段嵌入                   │
│ ┌──────────────▼──────────────────────────────────┐ │
│ │ FactorDef (精简后)                               │ │
│ │ ┌──────────────┐ ┌─────────────────────────────┐│ │
│ │ │ FactorList   │ │ FDI                         ││ │
│ │ │ (动态产物)    │ │ (运行时上下文)               ││ │
│ │ └──────────────┘ └─────────────────────────────┘│ │
│ │ ┌──────────────────────────────────────────────┐│ │
│ │ │ Meta: FactorMeta  (静态元信息)                ││ │
│ │ └──────────────────────────────────────────────┘│ │
│ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

核心变化：
1. 静态元信息从 FactorDef 分离到 `FactorMeta`
2. `__FACTOR_META__` 是模块元信息的唯一真相源
3. FactorDef 精简为 `FactorList + FDI + Meta`
4. Runner 统一处理 `defFactor` 返回 `List[Factor]` 的模块

## 3. FactorMeta —— 静态元信息

```python
# FactorDefContent.py

class FactorMeta(__QS_Args__):
    """因子定义的静态元信息 —— 描述一个因子定义模块的固有属性"""
    TargetTable: str = Field(title="因子表")
    IDType: str = Field(title="ID类型")
    Author: str = Field(default="Anonymous", title="作者")
    Description: str = Field(default="", title="描述信息")
    MaxLookBack: int = Field(default=365, title="最大回溯期")
    DefaultStartDT: datetime = Field(default=dt.datetime(2002, 1, 1), title="默认起始日")
    DTType: str = Field(default="自定义", title="时点类型")
    Freq: str = Field(default="1d", title="时点频率")
    DefScriptPath: str = Field(default="", title="定义脚本路径")

    # ---- 新增：分类与发现 ----
    Tags: List[str] = Field(default=[], title="检索标签")
    FactorDeps: Dict[str, List[Union[str, dict]]] = Field(default={}, title="依赖因子声明")
    # Dependencies 已废弃，统一使用 FactorDeps
```

## 4. FactorDef —— 精简后

```python
class FactorDef(__QS_Args__):
    """因子定义对象 —— 纯数据对象，组合静态元信息与动态因子列表"""
    FactorList: List[Factor] = Field(title="因子列表")
    Meta: FactorMeta = Field(title="静态元信息")

    @property
    def FactorNames(self) -> List[str]:
        return [f._QSArgs.Name for f in self.FactorList]
```

## 5. `__FACTOR_META__` 约定

每个因子定义模块在**模块顶部**声明元信息：

```python
__FACTOR_META__ = {
    "TargetTable": "stock_cn_factor_value",
    "IDType": "A股",
    "Author": "麦冬",
    "Description": "A股价值因子...",
    "MaxLookBack": 365 * 4,
    "Tags": ["估值", "基本面", "value"],
    "FactorDeps": {
        "stock_cn_status": ["if_listed"],
        "stock_cn_industry": ["citic2019_level1"],
        "stock_cn_day_bar_nafilled": ["total_cap"],
        "stock_cn_consensus_expectation": [
            "net_profit_fy0", "net_profit_fy1", "net_profit_fy2", "net_profit_fwd12m",
        ],
    },
    "DefScriptPath": __file__,
}

def defFactor(fdi: FactorDefInput) -> list:
    Factors = []
    # ... 因子构造，依赖因子通过 fdi.Factors["name"] 获取 ...
    return Factors
```

### `__FACTOR_META__` 字段规范

| 字段 | 必填 | 说明 |
|---|---|---|
| TargetTable | 是 | 输出因子表名 |
| IDType | 是 | ID 类型标识：A股 / 指数 / ETF / 港股 等 |
| Author | 否 | 作者，默认 "Anonymous" |
| Description | 是 | 一句话描述，用于向量检索 |
| MaxLookBack | 否 | 最大回溯天数，默认 365 |
| Tags | 否 | 检索标签列表 |
| FactorDeps | 否 | 依赖因子声明：`{表名: [entry, ...]}`，entry 为字符串或字典，`"*"` 表示全部因子 |
| DBDeps | 否 | 因子库依赖声明：`{FactorDB 逻辑名称: 用途说明}` |
| DTType | 否 | 时点类型，默认 "自定义" |
| Freq | 否 | 时点频率，默认 "1d" |
| DefaultStartDT | 否 | 默认起始日，默认 2002-01-01 |

## 7. 迁移要点

### 7.1 FactorDefContent.py

- 新增 `FactorMeta` 类
- `FactorDef` 删除静态字段，新增 `Meta: FactorMeta`

### 7.2 因子定义模块

每个模块：
1. 在 `"""docstring"""` 下方添加 `__FACTOR_META__ = {...}`
2. `defFactor` 签名改为 `defFactor(fdi: FactorDefInput) -> list`，直接返回 `Factors`
3. 只需 import `FactorDefInput`，不再 import `FactorDef`、`FactorMeta`

### 7.3 Runner 脚本

| 旧访问 | 新访问 |
|---|---|
| `factor_def.TargetTable` | `factor_def.Meta.TargetTable` |
| `factor_def.IDType` | `factor_def.Meta.IDType` |
| `factor_def.Author` | `factor_def.Meta.Author` |
| `factor_def.Description` | `factor_def.Meta.Description` |
| `factor_def.MaxLookBack` | `factor_def.Meta.MaxLookBack` |
| `factor_def.DefScriptPath` | `factor_def.Meta.DefScriptPath` |
| `factor_def.FactorList` | `factor_def.FactorList` (不变) |
| `factor_def.getFactor(...)` | `factor_def.getFactor(...)` (不变) |
